# Pet Slime

A tiny browser pet for GitHub Pages.

## First version

- Feed, play, rest, and pet your slime.
- Happiness, fullness, and energy stats.
- Progress is saved locally in the browser with `localStorage`.
- Stats gently decay according to elapsed time while the page is closed.
- Responsive, dependency-free HTML/CSS/JavaScript.

The first build uses a lightweight CSS slime while the Jobmania slime artwork remains the visual/source reference for the project. This keeps the app immediately playable without adding a framework or asset-loading dependency.
